# 📊 Sales & Demand Forecasting Project

## 🔍 Overview
This project builds a Machine Learning model to forecast future sales using historical retail data.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📈 Model Used
Random Forest Regressor

## 📊 What It Does
- Cleans sales data
- Creates time-based features
- Trains a forecasting model
- Predicts future sales
- Visualizes results

## 💼 Business Value
Helps businesses:
- Plan inventory
- Manage staffing
- Improve cash flow planning
- Avoid overstocking
