# Sales-Forecasting-ML
A Machine Learning-based Sales &amp; Demand Forecasting system built using Python and Scikit-learn. The project analyzes historical sales data, performs time-based feature engineering, and predicts future sales to help businesses with inventory planning, staffing, and financial decision-making.

## 🔍 Overview
This project builds a Machine Learning model to forecast future sales using historical retail data.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📈 Model Used
Random Forest Regressor

## 📊 What It Does
- Cleans sales data
- Creates time-based features
- Trains a forecasting model
- Predicts future sales
- Visualizes results

## 💼 Business Value
Helps businesses:
- Plan inventory
- Manage staffing
- Improve cash flow planning
- Avoid overstocking
